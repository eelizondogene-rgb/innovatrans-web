# INNOVATRANS — versión móvil de mapa limpio

- Abrí `index.html` con GitHub Pages (HTTPS).
- En teléfono: Mapa > Activar GPS > permitir ubicación.
- Dos controles flotantes: centrar mi posición y mostrar recorrido ilustrativo.
- Abrí “Ver últimos abordajes” para consultar registros.
- Se conserva el funcionamiento local de escaneo, reservas y reportes.
- No hay seguimiento entre dispositivos ni base de datos.
- La ruta de ejemplo no sigue calles reales; es ilustrativa.

Para subir al repositorio, reemplazá `index.html` y `demo-extra.js` en la raíz.
