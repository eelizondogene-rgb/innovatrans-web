# Mejoras de INNOVA TRANSLOGIC (versión demo)

- Se integró el logo facilitado de INNOVA TRANSLOGIC y se adaptó la identidad visual.
- Se agregó un panel superior con estado de ruta, número de abordajes, número de viajes y último registro.
- Se aclaró el uso opcional de un lector USB/Bluetooth tipo teclado: enfocar el campo e ingresar el código con Enter.
- Se incorporaron filtros por fechas en reportes y exportación CSV de los resultados filtrados.
- Se mantiene la lectura mediante cámara y la lógica de viajes y duplicados del prototipo original.

## Cómo usar

Abrí `index.html` para revisar la interfaz. Para **usar la cámara** en el teléfono, publicá esta carpeta completa mediante HTTPS (por ejemplo GitHub Pages, con el logo y el HTML en la misma carpeta). La cámara requiere permisos.

## Importante

Continúa siendo **una demo sin servidor ni base de datos central**: los registros solo se guardan localmente en el navegador y no se sincronizan entre dispositivos. No cargués datos reales de colaboradores ni gafetes hasta implementar acceso protegido, base de datos y controles adecuados.
