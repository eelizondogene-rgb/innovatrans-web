# Escaneo sin registro previo

Ahora cualquier código de barras no vacío puede registrarse directamente en una ruta activa.
Si el código no está en Pasajeros, el abordaje queda como «Pasajero sin identificar», y se muestra el código leído.
Si ya se escaneó el mismo código en ese viaje, se advierte y no se registra duplicado.
Si más adelante se asocia un nombre ficticio al código, los registros sin identificar pueden mostrarlo al renderizar la pantalla.
Esta demo sigue almacenando datos solo en el navegador. No subas datos reales de Walmart sin autorización y medidas de protección.

Para GitHub Pages: reemplazá `index.html` en la raíz del repositorio. `demo-extra.js` se conserva.
